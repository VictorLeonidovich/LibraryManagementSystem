## 🛠 Технологический стек

* **Backend:** Java, Spring Boot 4, Spring Data JPA (Hibernate)
* **Frontend:** HTML5, Thymeleaf
* **Сборка и зависимости:** Maven, MapStruct
* **Базы данных и миграции:** Liquibase
* **Мониторинг и валидация:** Spring Boot Actuator, Jakarta Validation

---

## 🏛 Архитектура проекта

Приложение реализует классическую монолитную архитектуру:
* **UI-слой:** Серверный рендеринг (SSR) веб-страниц с помощью Thymeleaf.
* **API-слой:** Выделенный REST API с DTO-маппингом (MapStruct) и собственным обработчиком исключений.
* **Бизнес-логика:** Сервисный слой на Java для обработки правил библиотеки.
* **Данные:** Модель данных (JPA-сущности) для книг, авторов, категорий и издателей.

## 📌 Документация API и тестирование

После запуска приложения интерактивная документация Swagger UI доступна по адресу:
👉 **http://localhost:8080/swagger-ui.html**

### Как тестировать защищенные эндпоинты в Swagger UI:
1. Раскрой блок **Авторизация** и выбери эндпоинт `/api/auth/login`.
2. Нажми **Try it out**, введи логин/пароль пользователя и выполни запрос.
3. Скопируй строку полученного токена (`token`) из JSON-ответа.
4. Поднимись в самый верх страницы Swagger и нажми зеленую кнопку **Authorize**.
5. Вставь скопированный токен в поле ввода и нажми **Authorize**. Теперь ты можешь полноценно тестировать все защищенные эндпоинты для ролей `USER` и `ADMIN` прямо из браузера!

## 📊 Мониторинг и метрики (Spring Boot Actuator)

В проект встроен модуль **Spring Boot Actuator** для мониторинга состояния приложения, метрик JVM и доступности базы данных в реальном времени.

Базовая точка входа:
👉 **http://localhost:8080/actuator**

Поведение системы настроено в зависимости от активного профиля:

### 🛠️ В профиле разработки (dev):
Доступны **все** встроенные эндпоинты управления (`management.endpoints.web.exposure.include=*`).
* **`/actuator/health`** — показывает расширенную информацию о состоянии системы и детальный статус подключения к БД H2 (`show-details=always`).
* **`/actuator/metrics`** — предоставляет полные системные метрики (использование памяти JVM, процессора, счетчики HTTP-запросов). Для просмотра конкретной метрики добавьте её имя в путь, например: `/actuator/metrics/jvm.memory.used`.
* **`/actuator/loggers`** — позволяет просматривать и динамически менять уровни логирования классов прямо на лету.

### 🚀 В продакшн профиле (prod):
В целях безопасности доступ к инфраструктуре строго ограничен (`management.endpoints.web.exposure.include=health,info`).
* Открыты только эндпоинты **`/actuator/health`** и **`/actuator/info`**.
* Отображение внутренней структуры и деталей подключения к PostgreSQL полностью скрыто (`show-details=never`) для предотвращения утечки данных об архитектуре сервера.
